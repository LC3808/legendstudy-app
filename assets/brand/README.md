# LegendStudy brand source assets

This is the canonical directory for owner-supplied LegendStudy brand originals.
The existing legendstudy.com logo supplied by the owner is the source of truth.
No original logo binaries are present as of Day 2 (2026-09-12).

Expected filenames when originals are supplied (these are conventions, not
existing files):

- `legendstudy-logo.png`: primary logo
- `legendstudy-logo-horizontal.png`: horizontal logo
- `legendstudy-symbol.png`: standalone symbol
- `source/`: unmodified original design/source files and provenance notes

Preserve supplied originals. Record origin/version when adding them; generate
mobile derivatives separately. Do not fabricate, trace, or redraw missing logos,
and do not describe generated Flutter placeholders as LegendStudy artwork.
Launcher icon replacement is pending actual originals. Existing Flutter launcher
icons remain unchanged. No runtime asset registration is needed until real
assets are introduced. UI palette remains as defined in `wiki/design-system.md`.
