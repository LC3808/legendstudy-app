# 논술 LAB 배너 — 티스토리 게시글 삽입 가이드 (Owner용)

대상: `legendstudy.com` 대학별 논술 기출 게시글. 삽입은 **Owner 수동**(자동 수정·배포 없음).
재료: [`essay-lab-banners-package.html`](essay-lab-banners-package.html) — 15개 대학 배너 블록. 각 블록은 `<!-- ========== 대학명 ========== -->` 주석 아래 `<!-- LS-ESSAY-BANNER:START --> … <!-- LS-ESSAY-BANNER:END -->`.

## 0. 한눈에
1. 패키지에서 **그 게시글 대학의 블록**(START~END) 복사 → 2. 게시글 **도입부 아래·기출 PDF 위**에 HTML로 붙여넣기 → 3. 저장 → 4. PC·모바일·링크 확인. 게시글당 **1개만**.

## 1. 대학 ↔ 블록 매칭 규칙
- 그 게시글이 **어느 대학**인지 보고, **같은 대학 블록**만 넣는다. (한양대 게시글 → 한양대 블록)
- 공개 15개 대학만: 한양·고려·성균관·서강·중앙·경희·건국·인하·동국·숭실·광운·한국외대·숙명여대·서울여대·한국항공. **목록 외 대학 게시글에는 넣지 않는다.**
- 한 게시글에 **배너 1개**. 같은 배너 반복 삽입 금지.

## 2. 삽입 방법 A — HTML 요소 추가 (권장, 본문 위치 지정)
1. 티스토리 관리 → **글 관리 → 해당 글 수정**(또는 새 글).
2. 편집기에서 배너를 넣을 줄(=도입부 문단 아래, 기출 PDF 안내 위)에 커서.
3. 왼쪽/줄 끝의 **＋(요소 추가)** 클릭 → **HTML** 선택.
4. 열린 입력창에 패키지의 **그 대학 블록(START~END) 전체**를 붙여넣기 → **확인/적용**.
5. 본문에 배너 카드가 보이면 성공. 위치가 어긋나면 드래그로 이동.

## 3. 삽입 방법 B — HTML 전체 편집 (대안)
1. 편집기 우측 상단 **모드 전환**에서 **HTML**(기본모드↔HTML) 선택.
2. 도입부 문단 뒤, 기출 PDF 안내 **앞** 위치를 찾아 **그 대학 블록(START~END)** 붙여넣기.
3. 다시 **기본모드**로 돌아와 레이아웃 확인 → 저장. (전체 HTML을 건드리므로 방법 A를 우선)

## 4. 삽입 위치
- **게시글 제목·도입부(첫 문단) 아래**, **기출 문제지/해설지 다운로드 안내 "위"**.
- 자료 다운로드·열람을 가리지 않게. 모바일에서 첫 화면을 과하게 차지하지 않게(배너는 1카드).

## 5. ⚠️ 티스토리 본문 주의 (중요)
티스토리 **게시글 본문**은 스킨과 달리 보안 필터가 있어, 붙여넣은 **`<script>`가 제거/비실행될 수 있다.**
- **디자인(HTML+`<style>`)·CTA 링크·UTM은 그대로 작동** → 배너는 정상 노출되고 **클릭 유입 추적(UTM)도 정상**.
- 다만 `<script>`가 제거되면 **GA4 `lab_banner_impression`/`lab_banner_click` 이벤트는 발화하지 않을 수 있음.** 이 경우에도 **UTM 기반 유입/클릭은 GA4 'Traffic acquisition'·UTM 리포트에서 집계**된다.
- **확인법**: 시범 삽입한 글을 열고 **페이지 소스 보기**에서 `__lsebInit` 또는 `lab_banner_impression` 문자열이 남아 있으면 스크립트 유지, 없으면 제거된 것.
- 스크립트가 제거돼 **이벤트 추적이 꼭 필요**하면: (a) UTM만으로 운영(권장·간단) 하거나, (b) 스킨 쪽에 공통 추적 스니펫을 넣는 별도 작업(TASK15 모달처럼)을 요청. 배너 자체는 그대로 둔다.

## 6. 저장 후 검증 (시범 1개 먼저 → 문제없으면 확대)
1. **저장/발행** 후 **PC·모바일** 양쪽에서 글 열어 배너 레이아웃·가독성 확인(깨짐·겹침 없음).
2. **CTA 클릭** → 해당 대학 LAB(`…/essay-lab/universities/{slug}/`)로 이동하는지. 로그인/가입 유도 화면이 떠도 정상(가입 전환 동선).
3. **딥링크**: 대학 화면으로 바로 가면 OK. 404·엉뚱한 페이지면 href를 `https://lab.legendstudy.com/essay-lab/`(공통 홈)로 교체(패키지에서 그 대학 블록의 href만 수정).
4. **추적**: 삽입 글 URL에 `?utm_source=tistory…`가 붙은 CTA로 들어가 GA4 **실시간**에서 유입/이벤트 확인. 스크립트 유지 시 `lab_banner_click`도 보임.

## 7. 롤백
- 방법 A: 본문의 배너 HTML 요소 선택 → 삭제. 방법 B: `START~END` 블록 삭제. 저장. (원복 즉시)

## 8. 운영 팁
- **점진 배포**: 먼저 1개 대학·1개 글에 넣어 5·6 검증 → 이상 없으면 대학별로 확대.
- 대학별 대표 글부터(유입 많은 기출 글). 같은 대학 여러 글에 넣을 땐 각 글에 그 대학 블록 1개씩.
- href·문구 수정이 필요하면 패키지 파일에서 고친 뒤 재배포(붙여넣기)하거나 Claude에게 요청.
- 로고: 현재 텍스트 대학명만. 공식 로고 자산·사용 허가가 확정되면 추가 가능.
