# TASK19 Owner 표시 정책 정정 — 2026-11-05

## 결정 및 구현

[기존 TASK19](task19-lab-ux-grade-cutoff-20261105.md)의 점수 출처·Registry 재사용·과거 결과 보존 원칙은 유지한다. Owner 추가 지시로 학생 화면의 자료 상태(추정/확정 여부 미제공)와 보조 표준점수 블록을 제거했다.

- 원점수가 있는 선택과목: 등급·원점수만 표시한다. 원점수 범위는 그대로 보존한다.
- 표준점수만 있는 선택과목: 등급·표준점수·추정 원점수를 구분한다. 출처가 확인된 추정값만 표시하고 표준점수에서 임의 환산하지 않는다.
- 출처는 접힌 메뉴에서 조회한다. 내부 자료 상태·원본 출처 기록은 삭제하지 않는다.
- 현재 검수 데이터의 표준점수 전용 120행에는 출처 검수된 추정 원점수가 없어 `—`로 표시한다. 추정값 표시 수신 처리는 준비됐지만 기존 SQL/RPC에는 별도 추정값 필드가 없으므로 **추정 원점수 데이터 연결은 미완료**다. 추가 출처 검수와 승인 대상 SQL 계약 보완 없이 숫자가 나타난다고 보고하지 않는다.

## 서비스 준비중 범위 확인

`source_catalog_page.dart`의 standaloneMathReady 및 `math_gateway.dart`의 hasReleasedMathQuestion은 대학명 예외 없이 공개 Catalog의 시험·문항 연결과 Provider 활성화를 확인한다. 건국대에만 적용한 처리가 아니다. 다른 대학 ID에도 동일하게 동작하는 회귀 검사를 추가했다.

상경·사회 혼합형은 기존 serviceExamIdsProvider의 시험 전체 공개 계약을 따른다. 일부 Math 문항 공개를 혼합형 전체 공개로 간주하지 않는다. 따라서 **등록된 모든 시험의 제한을 무조건 해제한 상태는 아니다**. 기존 검수·근거·실행 경로가 충족되지 않은 시험을 사용 가능으로 표시하지 않는다. 이번 수정에서 운영 공개 범위·DB·Provider·이용권을 변경하지 않았다. 운영 확대 범위의 이전 근거는 [운영 연결 보고서](app58-expanded-production-connection-20261104.md)를 따른다.
