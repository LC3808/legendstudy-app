# TASK19 Owner 표시 정책 정정 — 2026-11-05

## 결정 및 구현

[기존 TASK19](task19-lab-ux-grade-cutoff-20261105.md)의 점수 출처·Registry 재사용·과거 결과 보존 원칙은 유지한다. Owner 추가 지시로 학생 화면의 자료 상태(추정/확정 여부 미제공)와 보조 표준점수 블록을 제거했다.

- 원점수가 있는 선택과목: 등급·원점수만 표시한다. 원점수 범위는 그대로 보존한다.
- 표준점수만 있는 선택과목: 등급·표준점수·추정 원점수를 구분한다. 출처가 확인된 추정값만 표시하고 표준점수에서 임의 환산하지 않는다.
- 출처는 접힌 메뉴에서 조회한다. 내부 자료 상태·원본 출처 기록은 삭제하지 않는다.
- 현재 검수 데이터의 표준점수 전용 120행에는 출처 검수된 추정 원점수가 없어 `—`로 표시한다. 추정값 표시 수신 처리는 준비됐지만 기존 SQL/RPC에는 별도 추정값 필드가 없으므로 **추정 원점수 데이터 연결은 미완료**다. 추가 출처 검수와 승인 대상 SQL 계약 보완 없이 숫자가 나타난다고 보고하지 않는다.

## 서비스 준비중 범위 확인

`source_catalog_page.dart`의 standaloneMathReady 및 `math_gateway.dart`의 hasReleasedMathQuestion은 대학명 예외 없이 공개 Catalog의 시험·문항 연결과 Provider 활성화를 확인한다. 건국대에만 적용한 처리가 아니다. 다른 대학 ID에도 동일하게 동작하는 회귀 검사를 추가했다.

상경·사회 혼합형은 기존 serviceExamIdsProvider의 시험 전체 공개 계약을 따른다. 일부 Math 문항 공개를 혼합형 전체 공개로 간주하지 않는다. 따라서 **등록된 모든 시험의 제한을 무조건 해제한 상태는 아니다**. 기존 검수·근거·실행 경로가 충족되지 않은 시험을 사용 가능으로 표시하지 않는다. 이번 수정에서 운영 공개 범위·DB·Provider·이용권을 변경하지 않았다. 운영 확대 범위의 이전 근거는 [운영 연결 보고서](app58-expanded-production-connection-20261104.md)를 따른다.

## 2026-11-05 — 유사 시험 참고 원점수 승인·구현

Owner는 대략적 안내 목적의 다른 시험 기준 사용을 승인한 뒤, ‘해당 시험 추정값’과 ‘유사 시험 참고값’을 분리하는 제안에 “그래 반영해”라고 확정했다. 기존 미확인값 생성 금지 원칙을 실제 시험 점수에는 유지하고, 별도 참고 표만 추가한다.

- 해당 시험의 검수된 원점수 우선. 출처가 있는 해당 시험 추정 원점수는 기존 별도 계약으로 표시한다.
- 해당 시험 추정값도 없는 2026학년도9월/수능·2027학년도6월 국어·수학120행에 **유사 시험 참고 원점수** 표를 추가했다. 같은 과목·선택과목·등급·시험 종류/월의 이전 학년도 자료만 선택한다. 난이도 유사성을 검증한 예측 모델은 아니다.
- 이전 대상 시험 전체의 최소 하한~최대 상한을 표시한다. 임의 오차폭/표준점수 역산/미래 시험 참조 없음. 예: 2026학년도9월 화작1등급의 참고 범위91~98은 2024·2025학년도9월의 원점수 범위이며 해당 시험의 예상 등급컷이 아니다.
- 기준 시험명을 표 위에 표시하고 출처 메뉴에서 원본 게시글을 연다. ‘이 시험의 예상 등급컷이나 등급 판정 기준이 아닙니다’ 안내를 표시한다.
- 정확한 시험ID·과목ID·선택과목·등급으로 매핑하며 미확인9등급은 그대로 —. 실제 원점수/출처 확인된 추정값이 생기면 참고값을 숨긴다.
- [재현 생성기](../tool/generate_cutoff_comparison_reference.py)가 기존 reviewed_rows/registry_snapshot을 읽어 [표시 전용 상수](../lib/features/exams/cutoffs/historical_cutoff_references.dart)를 생성한다. 생성 후 dart format을 적용한다. 기존 JSON/SQL/RPC/채점/성적 저장에 참고값을 넣지 않는다.

보존 검토: (1) 기준 시험 학년·월과 적용 시점을 구분, (2) 원본 전사본과 생성기를 보존, (3) 원본/학생 결과 UPDATE 없음, (4) 학생 identity 무관, (5) 공개 참고자료이며 Learning/Outcome 판정 아님, (6) 공개 자료만 사용, (7) 도출 참고범위를 대상 시험 raw fact로 저장하지 않음.

검증: 모델·Widget9검사 PASS(120행 매핑/원점수·추정값 우선/미확인9등급/다른시험 차단/별도 표·기준 표시), analyze PASS. 기존 표1개 기대는 참고 표 추가에 맞춰 갱신. 참고표는 새 앱 빌드·실기기 검수 전이며 TEST61 설치본에는 아직 없다. 운영 DB/Store 변경0.
