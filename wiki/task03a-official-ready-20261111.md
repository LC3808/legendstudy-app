## 실제 자료로 발견한 SQL 후보 오류

전원정답 문항을 미응답으로 제출하고 나머지를 모두 맞추면 `correct_count=문항 수`,
`unanswered_count=1`이 된다. 기존 후보는 `correct_count+unanswered_count<=question_count`
제약 때문에 실제 완전한 제출을 저장하지 못했다(2022수능 생명과학Ⅱ50점 사례).

[로컬 SQL 후보](../supabase/candidates/task03_scoring_v2/candidate.sql)의 제약만 보완했다.
- mixed-v2: 각 카운터는 문항 수 이하, 정답/미응답 중첩 허용.
- mcq5-v1: 기존 합계 제약 그대로 유지.
- deferred consistency trigger는 실제 답안 snapshot으로 정확한 카운터를 재계산하여 검증한다.
- 미응답을 가짜 답안으로 바꾸지 않는다. 기존 정답·평가·이력 재채점/UPDATE 없음.
- **운영에는 적용하지 않았다.** 향후 적용 승인 시 이 제약 변경도 포함해 검수해야 한다.
