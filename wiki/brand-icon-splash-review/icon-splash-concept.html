LegendStudy+ · 앱 아이콘 & Splash 디자인 리뷰

2026-09-29 · UI/UX Lead · DESIGN REVIEW ONLY — 실제 아이콘/Splash 미교체. 공식 브랜드 자산 그대로 사용, 새 로고·심볼·색 없음.

현재 아이콘은 회전된 문서 심볼의 모서리가 캔버스 가장자리에 거의 닿아 “꽉 찬” 느낌입니다. 아래는 같은 흰색 캔버스 안에서 심볼 점유율만 줄여(70/75/80%) 여백을 확보한 비교안입니다. 심볼·색·형태는 그대로입니다.

3 · 제품명 표기 — + 위치 비교

공식 wordmark 이미지는 Splash에서 제외하고 텍스트 기반으로 구성합니다. 제품명 전체는 단색 near-black(#12161F), +도 같은 색(별도 orange 아님). 심볼의 orange는 그대로 유지됩니다.

두 안 모두 아래 Splash 실제 크기에서 렌더링됩니다. superscript는 각주가 아니라 제품명 일부로 자연스럽게 읽히는 선(≈0.5em, 우상단)으로 조정.

추천 B안 (심볼 + 레전드스터디⁺ + tagline), 이름 표기는 superscript ⁺, 색은 단색 near-black.

  • 아이콘과 한 시스템: 홈 화면의 75% 심볼이 그대로 확대되어 나타나 아이콘↔Splash 연속성이 명확.
  • tagline “나의 학습 기록이 쌓일수록, 나의 가능성은 선명해집니다.” — LAB의 “데이터가 쌓일수록, 나의 가능성은 선명해집니다.”와 브랜드 철학을 연결. 광고 문구 아님.
  • 노출 시간이 짧으면 tagline이 안 읽힐 수 있음 → 두 줄 tagline이 과하게 느껴지면 A안(심볼+이름)으로 축소. 같은 레이아웃 계열이라 전환이 자연스러움.

Native launch = orange 심볼 중심(흰 배경) → Flutter 첫 브랜드 프레임 = 심볼 + 레전드스터디⁺ + tagline. tagline을 네이티브 런치스크린에 넣지 않고 첫 프레임에서 페이드로 얹어, iOS/Android 12+에서 logo size jump·double splash 없이 이어지도록 구현.

6 · 플랫폼 구현 메모 (승인 시)

  • iOS: AppIcon.appiconset 15개 + 1024는 tool/export_launcher_icons.py가 소스에서 생성. 스케일 적용 = export 전에 소스를 흰 1024 캔버스에 75%로 합성(재도색·재드로우 없음). LaunchScreen.storyboard는 흰 배경 + 중앙 orange 심볼만(텍스트 없음).
  • Android: 적응형 ic_launcher_foreground는 이미 24dp 패딩(240/432). 레거시 mipmap-*/ic_launcher.png도 동일 75% 합성으로 통일. Android 12+ splash 테마(values-v31)는 흰 배경 + 심볼만, 세이프존 준수.
  • 이름/tagline = Flutter 첫 프레임: 네이티브 런치(심볼) → Flutter 첫 프레임(심볼 동일 위치 + 레전드스터디⁺ superscript, near-black + 두 줄 tagline 페이드). 네이티브에 텍스트를 넣지 않아 size jump·double splash 회피.
  • 세이프존/마스크: 75% 합성 후에도 export 스크립트의 세이프서클 검증(≤33dp) 유지·갱신. 원형·스퀴클·라운드 모두 문서 모서리 보존.
  • 제품명 레전드스터디+ / LegendStudy+ 유지, 심볼 orange 유지, +는 이름과 동일 near-black. 패키지·버전·딥링크·OAuth 불변.

이 페이지는 리뷰용입니다. 실제 적용은 Owner 선택(아이콘 %, + 표기, tagline 유무) 후 별도 승인 작업에서 export 스크립트 스케일 반영 → --write 재생성 → Flutter 첫 프레임 + 네이티브 splash 구성 → 기기 검증 순으로 진행합니다.
