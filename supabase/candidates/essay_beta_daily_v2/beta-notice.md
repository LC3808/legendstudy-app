# 인문논술 LAB 베타 무료 이용 안내

관리자 공지 작성용 승인 후보. category=beta, public=true, APP/WEB=true, 상단 고정 권장.
2026-11-10까지 게시하고, 종료 후에도 정책을 다시 확인할 수 있도록 공지를 보관합니다.

- 베타 대상 인문논술 시험에서 계정당 매일 무료 첨삭 1회를 제공합니다.
- 매일 오전 0시(한국 시간)에 갱신됩니다. 사용하지 않은 횟수는 이월되지 않습니다.
- APP과 WEB은 같은 계정의 무료 이용량을 공유합니다.
- 무료 이용권은 가입·구매 Credit 잔액과 별도로 표시됩니다.
- 베타 무료 첨삭의 첫 무료 재첨삭은 최초 완료 후 최대 14일 이내이면서 베타 종료 전까지 1회 가능합니다.
- 베타는 2026년 11월 10일까지이며, 11월 11일 00:00 KST에 종료됩니다.
- 종료 전에 정상 접수된 첨삭·재첨삭은 계속 처리됩니다.
- 일부 문항만 실패한 경우 완료 문항을 보존하고 기존 요청의 재처리 기능을 이용합니다. 예약을 중복으로 해제하지 않습니다.
- 전체 요청이 실패로 종료되면 무료 이용권을 한 번 복구합니다. 당일 자정이 지났거나 베타가 끝난 경우 이전 이용권의 기간이 연장되지는 않습니다.
- 신규가입 3 Credit과 구매 Credit의 기존 이용·재첨삭 정책은 유지됩니다.
- 불편한 점은 APP의 MY → 설정 → 문의·건의사항 또는 WEB 문의 화면에서 알려주세요.

운영 공지 게시와 베타 활성화는 별도 Owner 적용 절차입니다. 이 파일만으로 게시되지 않습니다.
