# 경희 인문·체육 / 사회 Registry 누락 일괄 보완

상태: **Owner 승인 후 APPLIED_METADATA_ONLY / STANDBY 아님**.
대상 Production: `stlhijzpjfgwwdgunlsd`.

보관된 공식 PDF 36개를 재사용해 인문·체육 11회차, 사회 13회차를 대조했다. 기존 등록 8회차의 ID를 보존한다. 신규 시험 16개와 기존 무문항 시험 4개에 총 51개 부모 문항을 등록한다. 기존 문항이 있는 4회차는 수정하지 않는다. 사회계 논제 III의 세부 답안 단위는 별도 입력 연결 대상이며 부모 문항 수와 혼동하지 않는다. 2027 모의 사회는 공식 문제·해설 모두 두 논제로 확인되어 과거 세 논제 형식을 적용하지 않는다.

## 적용 범위

- 신규 시험: 인문·체육 2022~2024 수시/모의, 2026 모의(7개); 사회 2022~2023 수시 오전/오후 및 모의, 2024 수시/모의, 2026 모의(9개).
- 기존 무문항 시험: 2025 수시/모의 인문·체육 및 사회(4개).
- 비활성/review 시험 메타데이터와 비공개 문항만 추가한다.
- 기존 시험·문항 ID, 공개 정책, RLS, 함수, Worker, Credit·Ledger·History를 수정하지 않는다.
- PDF 업로드/공개 및 평가 실행 승인은 이 SQL에 포함하지 않는다. 등록만으로 첨삭 가능이라 표시하지 않는다.

## 실행 순서

Owner의 이번 범위 승인 후 `precheck.sql`(2개 true) → `apply.sql` → `postcheck.sql`(exact_question_sets=true). 운영 사전 읽기 결과는 2개 true였다. Provider 호출·학생 답안 생성·빌드는 실행하지 않았다.

적용 SQL은 트랜잭션 안에서 대상 메타데이터를 잠그고 기존 무문항 상태와 신규 ID 부재를 재확인한다. 오류 시 전체 롤백된다. 재실행은 신규 ID 존재 검사에서 차단된다.

`rollback.sql`은 별도 승인 시 사용한다. 수정되지 않은 미공개 메타데이터만 제거하며 학생 기록/참조가 생기면 중단한다. CASCADE를 사용하지 않는다. 실제 서비스 연결 후에는 삭제 복구보다 전진 수정한다.

정확한 회차·문항·공식 자료 ID 및 해시는 `manifest.json`, 수량은 `summary.json`에 있다. 원본 자료 본문·학생 데이터·Secret은 포함하지 않는다.

## 적용 결과

Owner가 「누락 Registry 묶음 SQL 실행 승인」 후 사전 2개 true → 적용 성공 → 사후 exact_question_sets=true를 확인했다. 신규 16시험·기존 무문항 4시험에 51문항 등록 완료. 동일 SQL을 다시 실행하지 않는다. Provider 호출·Credit 차감·배포는 0. PDF·공식자료 패키지·실행 승인은 후속 작업이다.
